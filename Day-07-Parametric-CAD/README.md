# Day 07 — Parametric CAD Plate

## Project Overview
A rectangular mechanical plate with a cylindrical hole,
created using Python and CadQuery.

## Design Parameters

| Parameter | Value |
|---|---:|
| Length | 80 mm |
| Width | 50 mm |
| Thickness | 10 mm |
| Hole Diameter | 20 mm |

## Operations
- Box creation
- Cylinder creation
- Boolean subtraction
- Model validity check
- Volume calculation
- STL export
